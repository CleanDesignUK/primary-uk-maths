# Matchday Maths 5 checkpoint

The academy includes the phone game navigation, coach-led Year 1–6 practice, 247 exercise families with examples, written methods, the expanded Shop and the database-backed World League. [Verification](VERIFICATION.md)

The owner preview has a ranked backend. The static GitHub Pages build has the squad league. Before launching a public ranked service, select its host and public address, verify the database and access settings, then rebuild the marketing pages with that address. Existing player progress is saved per browser and site address. Players can export a local backup before moving to a new address.
